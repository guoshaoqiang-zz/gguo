# 魂斗罗 · Web Contra

一个使用原生 JavaScript + Canvas 2D 实现的网页版横版射击游戏，不依赖任何第三方游戏引擎或运行时依赖。

## 运行

```bash
npm start
```

打开 <http://localhost:3000> 即可游玩。可通过 `PORT` 环境变量修改端口：

```bash
PORT=8080 npm start
```

项目使用 ES Modules，也可以直接通过任意静态文件服务器托管（例如 `python3 -m http.server`）。

## 操作

| 按键 | 功能 |
| --- | --- |
| `A` / `D` 或 `←` / `→` | 左右移动 |
| `Space` | 跳跃 |
| `J` / `X` | 射击（按住连射） |
| `W` / `↑` | 向上瞄准 |
| `S` / `↓` | 空中向下斜射；地面下蹲 |
| `P` | 暂停 / 继续 |
| `R` | 重新开始 |

## 玩法

- 在 3200px 宽的关卡中向右推进，利用多层平台跳跃。
- 敌人会从前方生成并向玩家靠近，进入射程后会射击。
- 玩家拥有 3 条生命，受击后获得短暂无敌时间。
- 击中敌人可获得分数，生命耗尽后显示 `GAME OVER`，按 `R` 重新开始。

## 项目结构

```text
.
├── index.html            # 页面与开始界面
├── styles.css            # 页面、HUD 与开始界面样式
├── server.js             # 零依赖静态文件服务器
├── src/
│   ├── constants.js      # 关卡、角色、子弹、敌人与平台配置
│   ├── physics.js        # AABB 碰撞、移动积分、世界边界与向量工具
│   ├── game.js           # 纯逻辑游戏世界：状态更新、生成、碰撞、计分
│   ├── input.js          # 键盘输入映射
│   ├── renderer.js       # Canvas 渲染、摄像机、HUD、程序化美术
│   └── main.js           # 固定时间步长主循环与页面生命周期
└── tests/
    ├── physics.test.js   # 碰撞与物理工具单元测试
    └── game.test.js      # 游戏状态、射击、伤害与生成逻辑测试
```

核心游戏逻辑（`src/game.js`、`src/physics.js`）与浏览器渲染完全解耦，可在 Node.js 中直接实例化并测试。

## 测试

```bash
npm test
```

测试使用 Node.js 内置的 `node:test` 与 `node:assert`，覆盖：

- AABB 矩形碰撞检测；
- 平台落地、横向阻挡与世界边界限制；
- 玩家移动、跳跃、重力与落地；
- 射击冷却与向上瞄准；
- 子弹击中敌人、计分与实体清理；
- 敌方子弹与接触伤害、受击无敌时间；
- 生命耗尽后的游戏结束状态；
- 敌人定时生成与重置逻辑。

## 性能说明

- 游戏逻辑采用固定时间步长（1/60 秒），保证不同刷新率下行为一致。
- 主循环限制单帧最大补偿步数，避免卡顿后的“螺旋死亡”。
- 渲染仅绘制摄像机视野内的平台与实体，背景使用程序化绘制，无需加载大图资源。
- 支持高 DPI 屏幕（最多 2x 像素比），保持画面清晰。
